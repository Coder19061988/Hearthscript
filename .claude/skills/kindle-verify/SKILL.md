# Перевірка перед завершенням

Не кажи «готово», «працює» чи «виправлено», доки не запустив перевірку в цьому сеансі й не побачив результат. Звіт будуй на виводі команд: що запущено, скільки пройшло, що впало.

## Завжди

```powershell
python .claude/skills/kindle-verify/scripts/check_sync.py
./build.ps1 -Test
```

- **check_sync.py** за секунду ловить розбіжності між файлами:
  - поля балансу в balance.h, kFields і balance.json;
  - реєстр тестів у kTests і KINDLE_TESTS;
  - назви дій у ядрі, прелюдії та підписах Godot;
  - винятки, які кидає ядро, і класи прелюдії;
  - `__all__` прелюдії;
  - наявність `me.*` у довідці F1 і в документах.

  ПОМИЛКА означає, що щось зламається або тихо не працюватиме. УВАГА означає ймовірний недогляд.
- **`./build.ps1 -Test`** збирає все й запускає всі сценарні тести та godot_smoke. Смоук-тест з'являється лише тоді, коли Godot лежить за шляхом `KINDLE_GODOT_EXE` із CMakeLists.txt.

## Залежно від зміни

| Змінено | Додатково |
|---|---|
| Баланс; потреби, тепло, їжа | порівняй числа з `ctx.info` у `mvp_winter_survival` до й після; `mvp_bad_code` має й далі проходити (скіл kindle-balance) |
| Збереження, нове поле стану | `save_load` з перевіркою нового поля; у godot_smoke — збереження через меню |
| prelude.py, runtime.cpp | `sandbox`; приклад гравця: `./build/RelWithDebInfo/kindle_proto.exe run scripts/woodcutter.py --days 2` |
| Інтерфейс, 3D, вікна | скріншот (нижче) і огляд PNG |
| API, назви | документи, довідка F1 і підсвічування; check_sync.py показує прогалини |
| Швидкодія рантайму | `kindle_proto.exe bench --chars 50 --days 3` і тест `load_50` |

## Скріншот

Скріншот потребує вікна, тож без `--headless`. PNG клади в тимчасову теку (scratchpad сесії, якщо він є), а не в репозиторій.

```powershell
D:\Godot4\Godot_v4.6.2-stable_win64_console.exe --path godot --script res://tests/screenshot.gd -- out=<тимчасова тека>/shot.png hours=5
```

Параметри після `--`:

| Параметр | Що робить |
|---|---|
| `out=<шлях>` | куди зберегти PNG |
| `hours=N` | скільки ігрових годин прогнати перед знімком |
| `help=1` | відкрити довідку F1 |
| `construction=1` | креслення будинку, яке будують двоє персонажів |
| `save_dialog=1` | вікно збереження |
| `outcome=won` або `outcome=lost` | вікно підсумку гри |

Відкрий PNG інструментом Read і перевір:
- чи видно нове;
- чи не налазять написи;
- чи читається текст на фоні.

Скажи користувачу, де лежить знімок.

## Якщо щось упало

- **Не послаблюй перевірку, щоб тест пройшов.** Спершу з'ясуй, чи тест застарів через навмисну зміну дизайну, чи код зламав поведінку (скіл kindle-debug). Застарілий тест змінюй свідомо й пиши про це у звіті.
- **Кожне попередження check_sync.py переглянь.** Виправ його або поясни у звіті, чому лишаєш.
- **Незапущене — назви.** Якщо godot_smoke відсутній чи якусь перевірку не запущено, прямо скажи, що саме лишилося неперевіреним.
- **Скрипт сам розійшовся з кодом.** Якщо check_sync.py не може розібрати файл після рефакторингу, онови регулярні вирази в ньому, а не вимикай перевірку.
