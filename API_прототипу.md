# Kindlescript — міні-довідник API для прототипу

Цей документ фіксує точні назви всього, що використовує **перший технічний прототип** (див. «MVP», розділ 7). Назви тут — остаточні для прототипу; повний довідник API гри буде розширенням цього документа.

## 0. Загальні правила

* **Модель виконання.** Код кожного персонажа виконується зверху вниз. Кожен виклик дії (`me.chop_wood`, `me.sleep` тощо) — точка паузи: скрипт зупиняється, гра симулює дію протягом ігрового часу й продовжує скрипт з наступного рядка.
* **Кінець скрипта.** Якщо код дійшов до кінця, персонаж стоїть без діла; у журнал подій — запис «Код персонажа завершився».
* **Час на «роздуми».** Кожен виконаний рядок коду забирає кілька ігрових секунд (див. «Баланс прототипу»).
* **Переміщення.** Дія з цільовим об'єктом (`me.chop_wood(forest)`, `me.drop(storage)`) спершу автоматично веде персонажа до об'єкта; час дороги входить у тривалість дії.
* **Ресурси та предмети.**
  * *Ресурси* позначаються рядками: `"wood"`, `"bread"`.
  * *Інструменти* позначаються класами: `Axe`.
* **Доступні імена.** Скрипту доступні лише імена з цього документа та вбудовані функції Python без доступу до системи (`min`, `max`, `sum`, `len`, `range`, `print` тощо). `import` заборонений.

## 1. Глобальні функції

| Функція | Опис |
|---|---|
| `get(name)` | Повертає об'єкт за унікальною назвою (будівля, ліс, персонаж). Якщо не знайдено — `NotFoundError`. |
| `buildings(type)` | Список будівель заданого типу (`Storage`, `House`, `Forest`). |
| `time(h, m=0)` | Час доби, наприклад `time(18, 0)`. |
| `hours(n)`, `minutes(n)` | Тривалість, наприклад `hours(2)`. |
| `notify(text)` | Записує повідомлення в журнал подій. |
| `on(event, handler, priority=1)` | Реєструє обробник події. Менше число — вищий пріоритет. |
| `@on(event, priority=1)` | Те саме у вигляді декоратора. |

**Час і тривалість:** час доби можна порівнювати (`world.time >= time(18, 0)`) і додавати до нього тривалість (`world.time + hours(2)`). Порівняння діють у межах однієї доби (з 00:00 до 24:00).

## 2. `world` — світ (лише читання)

| Властивість | Тип | Опис |
|---|---|---|
| `world.time` | час доби | Поточний ігровий час. |
| `world.day` | `int` | Номер ігрового дня (з 1). |
| `world.is_night` | `bool` | Чи зараз ніч (див. «Баланс прототипу»). |
| `world.is_raining` | `bool` | Чи зараз іде дощ. |

## 3. `me` — поточний персонаж

### Властивості (лише читання)

| Властивість | Тип | Опис |
|---|---|---|
| `me.name` | `str` | Ім'я (незмінне). |
| `me.hunger` | `0–100` | Голод: 0 — ситий, 100 — крайній голод. |
| `me.fatigue` | `0–100` | Втома: 0 — бадьорий, 100 — виснажений. |
| `me.health` | `0–100` | Здоров'я: 0 — смерть. |
| `me.tool` | клас або `None` | Інструмент у слоті (наприклад, `Axe`). |
| `me.carrying` | `dict` | Що персонаж несе: `{"wood": 6}`. |
| `me.home` | будинок або `None` | Будинок, де живе персонаж. |

### Дії

Кожна дія займає ігровий час. Тривалі дії можна обмежити: `amount=` (обсяг), `until=` (до часу доби) або `hours=` (тривалість). Можна передати кілька обмежень — дія завершиться за першим, що настане.

| Дія | Опис | Можливі винятки |
|---|---|---|
| `me.go_to(obj)` | Іти до об'єкта. | `NotFoundError` |
| `me.go_home()` | Іти додому. | `NoHomeError` |
| `me.take(Axe, storage)` | Взяти інструмент зі складу в слот інструмента. | `NoItemError`, `ReservedError` |
| `me.put_back(storage)` | Повернути інструмент зі слота на склад. | `NoItemError` |
| `me.chop_wood(forest, amount=None, until=None, hours=None)` | Рубати дрова в лісі; дрова потрапляють у `me.carrying`. Потрібна сокира в слоті. Без обмежень рубає до заповнення ліміту ваги. | `NoItemError` (немає сокири), `TooHeavyError` (заповнено ліміт) |
| `me.drop(storage)` | Покласти все, що несе, на склад. | — |
| `me.pick_up(storage, resource, amount)` | Взяти ресурс зі складу (наприклад, `"bread"`). | `NoItemError`, `TooHeavyError` |
| `me.eat(resource)` | З'їсти ресурс, який персонаж несе. | `NoItemError` |
| `me.sleep(until=None, hours=None)` | Спати вдома (сам іде додому). Без дому спить на землі — відновлення гірше. | — |
| `me.rest(until=None, hours=None)` | Відпочивати на місці. | — |
| `me.wait_until(target, timeout=None)` | Чекати до часу доби (`time(6, 0)`) або поки умова (`lambda: ...`) не стане істинною. Повертає `True`, якщо дочекався, `False` — якщо минув тайм-аут. | — |
| `me.travel_time(obj)` | Скільки часу йти до об'єкта (не дія — не займає часу, окрім «роздумів»). | — |

## 4. Будівлі та місця

| Тип | Властивості та методи |
|---|---|
| `Storage` (склад) | `name`, `amount(resource)` — кількість ресурсу (`"wood"`, `"bread"`), `has_tool(Axe)` — чи є вільний інструмент. |
| `House` (будинок) | `name`. |
| `Forest` (ліс) | `name`, `trees_left` — скільки дерев лишилося. |

## 5. Події

| Подія | Коли настає |
|---|---|
| `Event.RAIN` | Почався дощ. |
| `Event.RAIN_STOPPED` | Дощ закінчився. |

* Обробник приймає `(me)` або `(me, event)`.
* Коли подія настає, поточна дія переривається (прогрес зберігається), виконується обробник, після чого персонаж повертається до перерваної дії. Якщо межа перерваної дії (`until=`) вже минула — дія вважається завершеною.
* Обробник із вищим пріоритетом (меншим числом) може перервати обробник із нижчим.

## 6. Винятки

Усі винятки дій наслідують `ActionError` і мають:

* `e.reason` — текстовий опис причини українською;
* `e.done` — скільки встигли зробити до невдачі (наприклад, кількість нарубаних дров).

| Виняток | Коли |
|---|---|
| `ActionError` | Базовий клас для всіх невдалих дій. |
| `NoItemError` | Потрібного предмета чи ресурсу немає. |
| `ReservedError` | Предмет зарезервував інший персонаж. |
| `TooHeavyError` | Перевищено ліміт ваги. |
| `NoHomeError` | У персонажа немає дому. |
| `NotFoundError` | Об'єкт із такою назвою не існує. |

**Необроблений виняток** зупиняє код персонажа: він стоїть без діла, а в журнал подій надходить запис із причиною.

## 7. Автоматичні записи в журнал подій

* Необроблений виняток (з причиною).
* Код персонажа завершився.
* Персонаж довго не виконує жодної дії (поріг — у «Баланс прототипу»).
* Високий голод / втома, падіння здоров'я, смерть.
* Перезапуск коду після зміни.

## 8. Приклад скрипта для прототипу

```python
@on(Event.RAIN, priority=1)
def hide_from_rain(me):
    me.go_home()
    me.wait_until(lambda: not world.is_raining, timeout=hours(3))

storage = get("Склад_1")
forest = get("Ліс_1")

while True:
    me.wait_until(time(6, 0))

    if me.hunger > 50:
        try:
            me.pick_up(storage, "bread", 1)
            me.eat("bread")
        except NoItemError:
            notify("Хліб закінчився")

    try:
        me.take(Axe, storage)
        me.chop_wood(forest, until=time(18, 0))
    except NoItemError:
        notify("Немає вільної сокири")
    except TooHeavyError as e:
        notify(f"Руки повні: нарубано {e.done}")

    me.drop(storage)
    me.put_back(storage)
    me.sleep(until=time(6, 0))
```

## 9. Що не входить у прототип

Обмежене знання та дошка оголошень, глобальні змінні, `estimate(...)`, одяг і тепло, будівництво, виготовлення, тварини, поле, пори року — додаються на етапі MVP і пізніше за планом.

## 10. Уточнення, прийняті під час реалізації прототипу

Документ не описував ці деталі явно. Тут зафіксовано, як вони працюють у прототипі (`core/prelude.py`, `core/world.cpp`).

* **`until=` і `wait_until(time(...))`** означають найближче настання цього часу доби. Наприклад, `sleep(until=time(6, 0))` о 22:00 — це 06:00 наступного дня. Якщо цей час минув менш ніж 10 хвилин тому (параметр `time_of_day_grace_minutes`), він вважається вже настанням. Без цього цикл «`sleep(until=time(6, 0))` → `wait_until(time(6, 0))`» пропускав би цілу добу через кілька секунд «роздумів».
* **`hours=`** приймає число годин (`hours=2`) або тривалість (`hours=hours(2)`).
* **Значення, які повертають дії:**
  * `chop_wood` повертає кількість нарубаного;
  * `wait_until` повертає `True`, якщо дочекався, або `False`, якщо минув тайм-аут;
  * решта дій повертають `None`.
* **`chop_wood` без обмежень** рубає, доки руки не стануть повні, і завершується без винятку. Якщо ж руки повні ще до початку або спрацювало обмеження `amount=`, `until=` чи `hours=`, викидається `TooHeavyError` з `e.done`.
* **`pick_up`** або бере ресурс повністю, або не бере нічого: якщо не вистачає ресурсу чи перевищено ліміт ваги, нічого не береться, а `e.done == 0`.
* **`sleep()` / `rest()` без обмежень** тривають, доки втома не впаде до 0.
* **`take(Axe, склад)`**, коли сокира вже в руках, нічого не робить. Сокира бронюється в момент виклику, тож інші отримують `ReservedError`, поки персонаж іде до складу.
* **Події:**
  * обробник `@on` спрацьовує в точці дії, тобто під час дії або очікування. Код, який лише обчислює без жодної дії, подію не отримає, доки не дійде до наступної дії;
  * подія з рівним або нижчим пріоритетом чекає, доки завершиться поточний обробник;
  * необроблений виняток в обробнику зупиняє весь код персонажа, і `try` в основному коді його не перехоплює.
* **`print(...)`** пише в журнал подій.
* **«Роздуми»** — це 2 ігрові секунди на кожен виконаний рядок, зокрема на кожен прохід однорядкового циклу та на код усередині `exec`. Умова `wait_until(lambda: ...)` перевіряється раз на ігрову хвилину.
